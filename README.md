# Nand2Tetris Capstone — Roll number 2501010091

## Personal values
- K = 91
- K mod 3 = 1: assembler must report invalid instructions with their source line number.
- K mod 4 = 3
- Box starts at screen row 91, is 20 rows high, and is 64 pixels wide.
- Screen word address at the first row: SCREEN + 32*91. Four words are written per row.

## Files
- `hdl/CPU.hdl`, `hdl/Memory.hdl`, `hdl/Computer.hdl`: Part A.
- `assembler.py`: two-pass assembler with line-numbered errors.
- `Box.asm`: draws/clears the assigned rectangle based on keyboard state.
- `Box.hack`: generated by running the included assembler.
- `report_template.docx`: report starter; replace all prompts and insert real screenshots.

## Important HDL dependencies
The HDL files use the standard Nand2Tetris chips `ALU`, `ARegister`, `DRegister`, `PC`, `RAM16K`, `Screen`, `Keyboard`, `ROM32K`, and standard gates/muxes. They must be available in the Hardware Simulator's built-in chip library or in your project search path. If your course requires your own lab implementations of these chips, place those HDL files in the same project/search path and test them too.

## Generate Box.hack
From this folder:
```bash
python assembler.py Box.asm
```
Expected output: `Box.hack` (the assembler prints the instruction count).

## Verify the assembler's required error feature
Create a temporary file `Bad.asm` containing:
```asm
@2
D=Q
```
Run:
```bash
python assembler.py Bad.asm
```
Expected: `Line 2: invalid instruction (unknown computation 'Q')` and a non-zero exit code.

## Test the four required programs
Obtain the official `Add.asm`, `Max.asm`, `Rect.asm`, and `Pong.asm` source files supplied with the Nand2Tetris course. Run this assembler on each:
```bash
python assembler.py Add.asm
python assembler.py Max.asm
python assembler.py Rect.asm
python assembler.py Pong.asm
```
Compare each output `.hack` file with the corresponding official assembler output. The output should match line-for-line.

## Part A test procedure
Use the official test scripts named in the assignment: `CPU.tst`, `Memory.tst`, `ComputerAdd.tst`, `ComputerMax.tst`, `ComputerRect.tst`. Run each in the Nand2Tetris Hardware Simulator and save screenshots of successful results.

## Part C run procedure
1. Open `Box.hack` in the CPU Emulator (load the program).
2. Set the screen view visible and run the program.
3. Press and hold a key: a black rectangle should appear.
4. Release all keys: the rectangle should clear.
5. Capture both states. The expected rectangle is at row 91, 20 rows high, 64 pixels wide.
